Technical data flow

Files, routes and credits, top to bottom: the IBM file to our slice, one model call per model x version x group through Nicrron, the local scorer, what goes to PRISM and what it costs, the two output files and the page that reads them.

Who looks at this, for what

The teammate operating the bench, and a judge who asks "show me the PRISM trace" or "how do you know it is the right row". Every box names the file or route a person can open.

How to read it

  • Top to bottom is time. Solid arrows carry data; the dashed arrow on the right is the slice file going straight to the UI (the UI never touches the runner or the scorer).
  • The thin line down the left margin is the scorer's output going to the results file; it is drawn in the margin to avoid crossing the PRISM band.
  • PRISM receives runs only after the local scorer has run, so each trace carries its local score and failure tag in metadata and the wrong-run list is known before any credit is spent.
  • The PRISM band is the Money Operations track (the team moved there at 11:14): Sessions is the trajectory box, Alert the alerts box, Root Cause then v2 the right-hand pair. The evaluator is kept only as an option in the credits note.
  • Credits: the right-hand note is the whole budget in one place. Nothing in the DATA, RUNS or SCORING bands costs a credit.

Assumed (dashed boxes)

  • File names under rings_bench: data/groups.json, prompts/v1.md, prompts/v2.md, facts.py, run_bench.py, score_bench.py. The brief named only data/bench_results.json and data/slice.js. The engine thread owns the real names.
  • That an unparseable model reply counts as a failed run (and not as "ordinary").
  • That the runner records each v2 step's input and output summary and duration, so the trajectory can carry them.

Receipts behind the PRISM boxes

Routes, the row-id gotcha, the empty-output error rule, the authorized-tools gotcha, the shared-workspace filter and the credit prices come from the practice-workspace runs copied to the board at 10:52 (PRISM_MECHANICS_RECEIPTS_from_board_1052.md). The seven step names and the fired latency alert are the engine thread's report at 11:40. Nothing on this page was called from this thread.
